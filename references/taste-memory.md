# Project Taste Memory

Use project taste memory to preserve explicit aesthetic preferences without turning one figure into a permanent rule.

Store it at `.research-figure/style-profile.json` in the user's project, never inside the installed skill.

## What to remember

Remember only explicit preferences such as:

- preferred font family or journal style;
- single-column versus double-column defaults;
- preferred legend placement;
- preferred qualitative palette order;
- preferred use of points, grids, panel spacing, and annotations;
- explicitly liked or rejected abstract reference traits.

## What not to remember

Do not store raw data, unpublished numeric results, reviewer comments, personal information, or copied paper images. Do not treat silence as approval.

## Update rule

Update the profile only when the user explicitly says they like, dislike, prefer, or want to reuse a style choice. Record abstract traits rather than copyrighted source images.
