# Figure Report Template

Keep this report next to important manuscript figures. Be factual and concise.

```markdown

- Reader comparison to notice first:
- Observational unit / dependence structure:
- Figure archetype:
- Panel evidence roles:

## Data and provenance
- Source file(s):
- Producing script/procedure:

## Encoding and statistics
- Selected chart(s):
- Why this encoding fits:
- Rejected candidate(s) and scientific reason:
- Uncertainty definition and unit of replication:
- Inferential test/model shown, if any:

## Publication contract
- Target venue/article type/stage:
- Requirement sources verified:
- Final width x height:
- Font/palette/color normalization:
- Export formats and raster DPI:
- Layer rasterization, if any:

## QA
- Machine preflight:
- Final-size visual review:
- Review-rubric verdict/score:
- Repairs made:
- Remaining warnings / AUTHOR VERIFY items:

## Caption-ready facts
- Quantity and units:
- Sample/N:
- Panel meanings:
- Statistical/uncertainty note:

## Limitations
- What the figure cannot establish:
- Unverified assumptions:
```

For venue-specific rules, include source URL/title and accessed date or link to a project-local journal profile.
